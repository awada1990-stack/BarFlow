Questions

Frequently asked questions

Do I need the internet?

Only once, to activate with your code. After that BarFlow and Cutting Plan work fully offline.

Can I try before I buy?

Yes. The free version of BarFlow BBS (30 shape codes, 20 rows, diameter 12 mm) and 3 free runs of Cutting Plan show you how everything works.

On how many computers can I use a licence?

One computer per licence. The 5-computer package covers up to five. To move a licence to another computer, write to us.

The code does not work, or I did not receive it.

Check the Spam folder first, then write to support@barflowapp.com with your order number. If we cannot fix it you can ask for a refund within 3 days.

Which Excel and Windows do I need?

Windows with Microsoft Excel 2016 or later for BarFlow BBS. Cutting Plan needs only Windows (and Excel to view the results).

My antivirus or Windows warns me.

Antivirus products may warn about any Excel file that contains macros, and Windows may ask you to confirm a new program (choose More info, then Run anyway). Get Cutting Plan from the Microsoft Store to avoid the warning, and download BarFlow only from this page.
