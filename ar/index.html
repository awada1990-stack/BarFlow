How it works

1. Download and try it free

BarFlow BBS works with the sample shape codes 100, 201 and 500 without a license. Cutting Plan gives you 3 free runs.

2. Buy a license

Pick a package below and pay by card or PayPal (Apple Pay and Google Pay too, where your device and browser support them). A short 16-character activation code arrives by email within a minute.

3. Activate

Open the program, press License, type the code and press Activate. You need the internet only for this one moment; afterwards the program works offline.

BarFlow (BBS) – Excel

  • Bar bending schedules per BS 8666 with real shape drawings
  • Cutting length, total number and weight calculated automatically
  • Millimetres or feet-inches (lb), English or Arabic
  • Export the schedule to DXF for AutoCAD
  • Print to A4 with page numbers
  • Cutting list export to Excel

BarFlow Cutting Plan

  • Turns your bar list into a stock-purchase and cutting plan: which bars to buy, how to cut each one, the waste and the cost
  • Results in Excel: a plan per diameter, a summary and a purchase order
  • English or Arabic. 3 free runs, then a license
  • Works alone, or together with BarFlow: press Optimize in BarFlow

Questions

Do I need the internet?

Only once, to activate with your code. After that BarFlow and Cutting Plan work fully offline.

On how many computers can I use a license?

One computer per license. The 5-computer package covers up to five. To move a license to another computer, write to us.

The code does not work, or I did not receive it.

Check the Spam folder first, then write to support@barflowapp.com with your order number. If we cannot fix it you can ask for a refund within 3 days.

Which Excel and Windows do I need?

Windows with Microsoft Excel 2016 or later for BarFlow (BBS). Cutting Plan needs only Windows (and Excel to view the results).

My antivirus or Windows warns me.

Antivirus products may warn about any Excel file that contains macros, and Windows may ask you to confirm a new program (choose More info → Run anyway). Only download BarFlow from this page.
